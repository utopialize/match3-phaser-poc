# Contributing to Phaser Match-3 Engine

Thanks for considering a contribution!

## Code of Conduct

Be respectful, constructive, and inclusive. Help others succeed.

## How to Contribute

- Report bugs with clear steps and expected/actual results.
- Propose features with the problem you’re solving.
- Improve docs (typos, examples, clarifications).
- Tackle open issues or propose your own.

## Development Setup

```bash
git clone https://github.com/your-username/phaser-match3-engine.git
cd phaser-match3-engine
npm install
npm run dev
```

## Pull Request Process

1. Create a branch (`feature/...` or `fix/...`).
2. Keep changes focused and documented.
3. Add/update tests or samples if relevant.
4. Ensure `npm run build` succeeds.
5. Write clear commit messages.
6. Open a PR describing the change and testing done.

## Code Style

- TypeScript strict, no `any` unless justified.
- Prefer configuration over hardcoded values.
- Keep TSDoc/comments concise and meaningful.
- Run linters/formatters if available (or match existing style).

## Reporting Bugs

Include:
- Environment (OS, browser, Node/npm versions).
- Steps to reproduce.
- Expected vs actual behavior.
- Screenshots/logs if helpful.

## Suggesting Features

Describe the use case, why it matters, and any constraints. Sketch API/config ideas when possible.
