# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-11-26

### Added
- Initial release of the Phaser Match-3 Engine.
- Core match-3 gameplay with swaps, validation, cascades, and hints.
- Special gems (line, nova, supernova) with wave-based resolution.
- Centralized configuration (`GameConfig.ts`) and theming (`ThemeConfig.ts`).
- Procedural textures, animation system, and HUD controller.
- TSDoc documentation and developer tools (toggle with `D`).
- Neutral, theme-driven UI and storage keys.

### Documentation
- English and French READMEs.
- CONTRIBUTING guidelines.
- Configuration reference in `docs/CONFIGURATION.md`.
